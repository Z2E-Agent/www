## Read AGENTS.md first

`AGENTS.md` is the source of truth for commands, CI/commit flow, generated code, path aliases, and patches. Key points that bite if missed:

- **Bun only** — `bun.lock` is Bun-specific.
- `bun run dev` (Turbopack), `bun run build`, `bun run lint` (no args — flat ESLint config). No test suite.
- `.husky/pre-commit` runs `bun run build` on every commit — commits are slow and fail if the build fails.
- `.source/` is generated by `fumadocs-mdx` (postinstall/dev/build), gitignored — never edit or commit. If `fumadocs-mdx:collections/*` imports fail, run `bun install` or `bun run build`.
- Default branch is `master`. ESLint pinned to `^9` (10 blocked upstream); TypeScript pinned to `^6` (Next 16 rejects TS 7).

## Architecture

A Fumadocs (Next.js 16 App Router, React 19, Tailwind 4) documentation site for the Z²ᴱ red-team framework. The docs content is decoupled from the app shell:

- **Content**: MDX under `content/docs/`, with `meta.json` per directory controlling sidebar order. Frontmatter/meta schemas are enforced in `source.config.ts` — extend the schema there before adding new frontmatter fields.
- **Wiring**: `source.config.ts` (`defineDocs`) → generated `.source/` → `src/lib/source.ts` (Fumadocs `loader`, `baseUrl: '/docs'`) → consumed by routes.
- **Routes** (`src/app/`): `docs/[[...slug]]/page.tsx` renders MDX pages; `(home)/` is the landing page; `og/docs/[...slug]/route.tsx` and `opengraph-image.tsx` generate OG images; `llms-full.txt/route.ts` serves full-text for LLMs; `api/search/route.ts` is Fumadocs search.
- **Aliases**: `@/*` → `src/*`, `fumadocs-mdx:collections/*` → `.source/*`.

Deploy target is ambiguous (`@opennextjs/cloudflare` dep vs README's Vercel) — confirm before touching build/runtime config.
